# YouthTech Summit 2026

A responsive website for a fictional technology conference bringing young people together to explore web development, artificial intelligence, and innovation.

## Built With

* HTML5
* CSS3
* JavaScript
* Google Fonts (Lato)

## Features

* Responsive home and about pages
* Mobile navigation menu
* Featured speakers generated dynamically with JavaScript
* Conference program section
* Responsive layouts for mobile and desktop screens

## Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
